# ngo-ccsh-backend

Backend em Django REST API do sistema de controle orçamentário da UFSM, desenvolvido originalmente para o Núcleo de 
Gestão Orçamentária do Centro de Ciências Sociais e Humanas.

Para instruções de como rodar o projeto em ambiente de desenvolvimento, consulte o
arquivo [DESENVOLVIMENTO.md](DESENVOLVIMENTO.md).

Para instruções de como colocar o projeto em produção, consulte o arquivo [PRODUÇÃO.md](PRODUÇÃO.md).

# Agents

Arquivo de prompts para a IA não se perder no desenvolvimento do projeto.

* O frontend deste projeto está https://github.com/COPLIN-UFSM/ngo-ccsh-frontend, e geralmente fica na pasta
  `../ngo-ccsh-frontend` em relação a este projeto.
* O backend roda na porta http://localhost:8080 e o frontend roda na porta http://localhost:5173
* As credenciais de acesso ao backend são:
    * Usuário: `00000000001`
    * Senha: `zecarioca`
* Verifique o arquivo [DESENVOLVIMENTO.md](DESENVOLVIMENTO.md) para mais instruções.
